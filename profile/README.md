# BotSat Organization

Welcome to the BotSat organization! This is a collection of repositories related to our CanSat-style payload project that we launch using a Water Rokit bottle rocket system.

## Project Overview

BotSat is a fun project that combines elements of CanSat competitions with DIY rocketry. We use a Water Rokit kit to launch our payload, which contains various sensors and telemetry equipment to collect data during flight.

The project is inspired by traditional CanSat competitions but with our own twist - using a water-powered bottle rocket as the launch vehicle. This makes the project more accessible and fun while still providing valuable learning opportunities in rocketry, electronics, and data analysis.

Checkout https://www.k-si.com/projects/botsat/ for more information!
